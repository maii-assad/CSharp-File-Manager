# C# File Manager

A simple console-based file management application built with C# to practice fundamental programming concepts and file system operations.

## Features

* **Read:** Display the contents of a text file.
* **Write:** Create or overwrite a file with new content.
* **Append:** Add content to an existing file.
* **List:** Display files and directories inside a specified path.
* **Info:** Show information about a file or directory, including creation date and last modification date.
* **Mkdir:** Create a new directory.
* **Remove:** Delete a file or directory.
* **Exit:** Close the application.

## Technologies Used

* C#
* .NET
* `System.IO` for file and directory operations

## How to Run

1. Clone this repository:

   ```bash
   git clone (https://github.com/maii-assad/CSharp-File-Manager.git)
   ```

2. Open the project in Visual Studio.

3. Build and run the application.

4. Enter a command followed by a file or directory path.

## Example Commands

```text
read C:\Files\example.txt
write C:\Files\example.txt
append C:\Files\example.txt
list C:\Files
info C:\Files\example.txt
mkdir C:\Files\NewFolder
remove C:\Files\example.txt
exit
```

**Note:** Replace the example paths with valid paths on your computer. The application must have the necessary permissions to access the specified files and directories.
